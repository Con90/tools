# tools

A collection of small personal tools.

| Tool | What it does |
|------|--------------|
| [**Planner/**](Planner/) | Cross-platform (Linux/Windows/Mac) daily & weekly planner app. Drag-and-drop time blocking, repeating tasks, week and 3-day views. Electron. |
| [**pubmed-scraper/**](pubmed-scraper/) | On-demand PubMed scraper that finds new articles matching configured searches and writes them to CSV/text with APA-style citations. Python. |
| [**seal-pomodoro/**](seal-pomodoro/) | Pomodoro timer that lives on the desktop as a frameless, always-on-top harbour seal. Countdown on its flank, click to start, drag to move. Python + GTK. |
| [**stylist/**](stylist/) | Personal styling app: enter your usual sizes or body measurements plus brand size charts, get the right size per brand with UK/EU/US equivalents; upload face photos to get your seasonal colour palette; body-shape style advice and an optional Claude-written style brief. Runs locally. Colour palettes, style suggestions and virtual try-on to follow. Python + local web UI. |

Each folder has its own README with install and usage instructions.
